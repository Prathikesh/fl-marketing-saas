# Report chapters

Write-up of the individual research component — *Privacy-Preserving Continuous Learning Framework
for Multi-Tenant Marketing AI*. Each chapter maps to the implemented system; every result is
measured and reproducible via the `make` targets in the project README.

| Chapter | File | Covers |
|---------|------|--------|
| 1 | [01_introduction.md](01_introduction.md) | Problem, motivation, aim, objectives, contributions |
| 2 | [02_background.md](02_background.md) | Federated learning, DP, robustness, personalization, delayed feedback |
| 3 | [03_methodology.md](03_methodology.md) | System design, data decisions, model choice, experimental design |
| 4 | [04_implementation.md](04_implementation.md) | Architecture, modules, API, UI, MLOps |
| 5 | [05_results.md](05_results.md) | All measured results and the evaluation of each claim |
| 6 | [06_discussion.md](06_discussion.md) | Interpretation, limitations, threats to validity |
| 7 | [07_conclusion.md](07_conclusion.md) | Summary, contributions, future work, references |

All figures and tables in Chapter 5 are reproduced by the scripts in `scripts/` and visualised in
[notebooks/fl_marketing_complete.ipynb](../../notebooks/fl_marketing_complete.ipynb).
