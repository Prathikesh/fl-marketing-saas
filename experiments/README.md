# Experiments

Holds experiment outputs and exploration notebooks.

- `results/` — metrics tables and plots produced by the evaluation scripts (small files tracked;
  large artifacts are git-ignored).
- `notebooks/` — exploratory analysis:
  - `01_data_exploration.ipynb` — inspect the raw datasets.
  - `02_tenant_heterogeneity.ipynb` — confirm the tenants differ and one is data-poor.
  - `03_results_analysis.ipynb` — analyse comparison and privacy results.

See [../docs/experiment_guide.md](../docs/experiment_guide.md) for how to run experiments.
